# CP04 V2E — Primary vintage knob: molded grip geometry

**Status:** candidate geometry only / owner approval **NOT granted**.
**Scope:** MW-CONTROL-001. Builds on CP04 V2D and G2.1B; does not replace the toggle or meter work.
**Production:** no runtime, DSP, MIDI, presets, automation, deployments or DAW UI imports changed.

## Implemented

- Original continuous turned/molded knob body, 36 mm nominal study diameter, 9.25 mm installed crown height (not manufacturer dimensions).
- Forty evenly spaced, bounded, rounded-end recessed grip flutes modeled as real subtractive CAD geometry (62.4146 mm³ removed); not SVG bands or texture-painted ridges.
- Blind 6.2 mm shaft bore; 0.19 mm recessed indicator with 0.04 mm sidewall gap; separate fixed under-body mounting washer.
- Three independently exported min / middle / max pointer orientations (-135°, 0°, +135°), unchanged body topology, three named STEP/GLB parts per state.
- 14 internal CAD checks, including inter-part solid intersections at all states and an intentionally displaced pointer correctly detected as a collision.
- Dedicated review-only GitHub Action reconstructs CAD, verifies the 6 output files, SHA-256 inventory and watertightness; uploads temporary artifact.

## Reproduce locally

Install cadquery, numpy and trimesh, then execute:

    python design-assets/motionwave-ui-lock/v2e/cp04_v2e_knob_cad.py audit-out/cp04-v2e

Outputs: three STEP, three GLB and cad-verification.json.

A separate downloadable conversation package adds full-size and 96/160/256px transparent VTK study renders. Those PNGs and the expanded render utility are NOT checked into GitHub and are NOT generated by the CAD-only CI. Do not call VTK's provisional point-lit shading calibrated Cycles/PBR art.
